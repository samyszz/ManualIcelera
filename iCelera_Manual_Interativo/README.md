# Manual Interativo de Suporte Técnico iCelera

Projeto front-end em HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — estrutura da interface
- `styles.css` — identidade visual, responsividade e modo escuro
- `script.js` — navegação, busca, filtros e conteúdo das 9 seções
- `assets/logo-icelera.jpg` — logo enviada

## Como executar

1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Não é necessário servidor para testar a versão básica.

## Funcionalidades

- Capa visual inspirada no layout solicitado.
- Menu lateral com as 9 seções.
- Cards de acesso rápido.
- Busca por erro, equipamento, procedimento e palavra-chave.
- Página detalhada de cada seção.
- Procedimentos em passo a passo.
- Modo escuro.
- Aumento do tamanho da fonte.
- Layout responsivo para celular, tablet e desktop.

## Base de conteúdo

O conteúdo técnico foi estruturado a partir do arquivo `Manual_de_Suporte_Tecnico_iCelera.docx` fornecido na conversa. A organização inclui as nove seções e seus procedimentos.
